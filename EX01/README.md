# The triangle drawing 

This exercise is about drawing some triangles on the screen using opengl in immediate mode.
For this we have to take the three clicked points from the window and convert its cordinates to the OpenGL cordinates. 
Also we have a buffer of points with size 3 which we store points of the triangle to it and then we flush it to the OpenGL. 
We also use a random color every time we want to draw a triangle.
